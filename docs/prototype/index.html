차량 이벤트 시뮬레이터 Virtual Console 역할

실제 차량 대신 버튼으로 차량 상태를 바꿉니다. Pleos Connect 에뮬레이터에서는 Virtual Console이 같은 역할을 합니다.

SDK 이벤트 로그 앱이 받은 신호

    모든 방문은 자동으로 기록되고 폴라로이드 스타일 드라이브 카드가 만들어집니다. 반복되는 패턴은 루틴 스탬프가 되고, ★ 다시 가고 싶은 곳은 다음 추천에 쓰입니다. 모든 조작은 차량 화면에서 탭 한 번으로 끝납니다. 방문 기록과 장소는 시연용 예시 데이터입니다.
